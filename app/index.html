      REST API

      The same engine runs as serverless functions on Vercel.

      GET/api/healthService status
      POST/api/parseResume text → structured JSON (or {"job": "..."} to parse a JD)
      POST/api/rankJD + list of resumes → ranked results with explanations
      curl -X POST https://<your-app>.vercel.app/api/rank \
  -H "Content-Type: application/json" \
  -d '{"job": "Senior Data Scientist, 5+ years Python, NLP, AWS",
       "resumes": [{"name": "a.txt", "text": "..."}]}'

      How the fit score works

      1. Parse. Text is pulled out of the file (two-column PDFs are read column by column), split into sections, and turned into JSON: jobs with durations, education, skills, and quantified achievements.
      2. Normalise skills. "K8s", "EKS" and "Kubernetes" all become one canonical skill. Implied skills are added (PyTorch ⇒ Python, Deep Learning).
      3. Blind. Names, contact details, graduation years, personal-details blocks and identity-linked groups are redacted before scoring.
      4. Stage 1 – retrieval. TF-IDF vectors with canonical skill tokens, cosine similarity against the JD.
      5. Stage 2 – rerank. The JD is compared with each job block separately; recent roles weigh more.
      6. Stage 3 – fit score. 50% semantic + 30% experience + 20% skills. Experience below the requirement decays exponentially. Skills get partial credit for close alternatives (Azure for AWS ≈ 70%).
